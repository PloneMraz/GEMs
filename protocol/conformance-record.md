## What the gaps cluster into

The requirements that cannot be demonstrated fall into five groups. Four are each one purchase away from being testable; the fifth is reference code not yet written, and needs no purchase:

| Group | Requirements | What it would take |
|---|---|---|
| A target board and firmware | C-13, C-14, C-15 | one compute module and a bus interface |
| Sensors, contact surfaces and a drive's faculties | C-2, C-5, C-12, C-17 | one instrumented joint with force sensing, on a bought drive with its protections |
| Structure | C-7, C-16 | one limb that can be loaded and dropped |
| Root of trust and radio | C-10, C-11, C-19 | a secure element and a low-power radio |
| Reference code | C-3, C-6, C-18, C-19, C-20, C-21 | the body-datum (S-10), the estimator (F-4), acknowledgement in the buffer, the unit's storage and its windows |

The cheapest is the reference code, which costs only work; of the purchases, the cheapest is the root of trust and radio, and the one that unblocks the most rows is the first.
